## 📝 Project Description

This project showcases how to integrate a **full-screen video slider** in the background with various sections of text content. The **navigation menu** allows users to easily switch between different video slides and corresponding content.

---

## ⚡ Features

- **Video Slider**: The homepage features a video slider with multiple background videos that transition smoothly when clicking on the navigation buttons. 🎬

- **Interactive Navigation Menu**: An elegant and responsive menu button toggles the navigation visibility. 📡

- **Responsive Design**: The project is optimized for all screen sizes, providing an 
excellent experience on both desktops and mobile devices. 📱

- **Smooth Transitions**: The slider buttons offer smooth transitions, highlighting the current active content and video. ✨

---

## 🛠️ Tech Stack

- **HTML**: Structure of the webpage.

- **CSS**: Styles for the layout, animations, and responsiveness.

- **JavaScript**: Interactivity for the navigation menu and slider.

- **Google Fonts**: Used for the beautiful "Nunito Sans" font.

- **FontAwesome**: Icons for social media links in the footer. 🎨

## 🚀 Installation

To get this project up and running on your local machine:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/sudhanshu-j/slider-background-video.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd slider-background-video
   ```

3. **Open the `index.html` file in your browser to view the project**.

## 🖥️ Usage

- **Video Slider**: Clicking on a navigation button will switch the background video and the text content.

- **Navigation Menu**: On desktop, the navigation menu is fixed at the top. On mobile devices, click the menu icon to toggle the navigation bar.

- **Interactive Buttons**: The video slider buttons at the bottom allow you to navigate through the different sections of the page.

## ✨ How It Works

### HTML

- The `index.html` file contains the layout of the webpage, including a `<video>` element for each background video.

- The navigation menu links are controlled by the `<header>` element.

### CSS

- The `style.css` file controls the appearance of all elements, with media queries for responsiveness and animations for the slider and menu.

- It also uses custom fonts and icon sets to enhance the design.

### JavaScript

- The `script.js` file adds interactivity:
  
  - When the menu button is clicked, it toggles the visibility of the navigation.
  
  - When a navigation button is clicked, it switches the video slide and updates the active content.
